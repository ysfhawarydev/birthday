# 🎂 Birthday

> A cute, romantic, and interactive birthday experience. 💗

A beautifully animated birthday website designed as a special digital surprise, filled with memories, music, love, and little interactive moments. ✨

## ✨ Features

- 🎀 Romantic and cute design
- 💗 Smooth animations and transitions
- ✨ Floating hearts, sparkles, flowers, and decorative elements
- 🎵 Looping background music
- 📸 Interactive memories gallery
- 🖼️ Fullscreen photo viewer
- 💌 Animated love letter
- 🎂 Interactive birthday cake and candles
- 🎉 Confetti effects
- 🎁 Interactive surprise section
- 📱 Fully responsive design
- ⚡ Fast and lightweight

## 🛠️ Built With

- React
- TypeScript
- Vite
- React Router
- Framer Motion
- Lucide React
- CSS3
